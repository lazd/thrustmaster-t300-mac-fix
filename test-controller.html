Thrustmaster T300 Mac Fix

Upset your T300 doesn't work in macOS?

Pedals act like buttons, the steering wheel is imprecise, and everything is mapped wrong, yet Thrustmaster doesn't offer a macOS driver to fix it...

Let's fix it

Download the fix, install it, then come back to this page to see it work!

Download latest DMG
  1. Install T300 Mac Fix

    Open the DMG and run "Install T300 Mac Fix", type your password when prompted.

  2. Connect the wheel

    Set the mode switch to PS3 / PC and connect it to your Mac over USB.

  3. Wake controller access

    Press any wheel button, turn the steering wheel, press the pedals, and watch the live input below!
